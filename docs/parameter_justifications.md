# DGM Model Parameters, Assumptions, & Literature Justifications

This document provides a comprehensive, field-by-field scientific reference for all physical constants, default parameters, underlying geomorphic assumptions, bounded sampling distributions, and algorithmic invariants supporting the **DeltaGraphModel (DGM)**.

The document is organized into two primary parts:
- **Part I: Config-Tunable Parameters & Boundary Conditions** (Sections 1–8), matching the exact structure and keys of [`config/default_config.yaml`](../config/default_config.yaml). Each parameter distinguishes natural empirical geomorphic foundations from calibrated modeling heuristics and algorithmic control flags.
- **Part II: Non-Tunable Geomorphic, Physical, & Algorithmic Invariants** (Sections 9–12), documenting hardcoded physical scaling laws, numerical bounds, and topological constraints embedded in the model core.
