# Security Policy

## Supported Versions

DeltaGraphModel (DGM) is under active development. The following versions currently receive security and bug fix updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in DeltaGraphModel, please report it privately to the maintainers rather than opening a public issue.

You can report vulnerabilities by:
- Sending an email to **`jayaram.hariharan@kestrelintelligence.com`** with the subject line `[SECURITY] DeltaGraphModel Vulnerability Report`.
- Or opening a private draft security advisory via [GitHub Security Advisories](https://github.com/jay-kestrel/dgm/security/advisories/new).

Please include the following information in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal script to reproduce the issue.
- Any suggested fixes or mitigations.

### Response Timeline
- Maintainers will acknowledge receipt of the report within **48 hours**.
- A preliminary assessment and proposed mitigation plan will be communicated within **7 business days**.
- Once a fix is confirmed, a patched pre-release will be published, and public advisory details will be coordinated.
